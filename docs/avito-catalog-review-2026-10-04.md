## Проданные И Неопубликованные

Из основной подготовки исключены т8, т21, т10, т19 и т28: products и оффер
магазина имеют sold/0. В inventory snapshot у каждого всё ещё quantity=1.
Не возвращать их в продажу по старому snapshot. Следующая свежая выгрузка кассы
должна снять расхождение; в этой итерации остатки не переписывались.
На публичных страницах всех пяти присутствует пометка «Продано».

Gold т38, два QA-устройства, demo-импорт и четыре архивных legacy-прототипа
не входят в список загрузки. Полный перечень есть на листе сверки книги.

## Публичные Проверки

- 24/24 карточки возвращают HTTP 200 по каноническому `/product/<id>`;
  название, публичная диагностика и технические характеристики модели присутствуют.
- `/device/<id>` является HTTP 301 compatibility redirect. Первый строгий
  no-redirect запуск не принял этот переход; адреса исправлены по repo route,
  затем страницы проверены повторно. Это не отказ production-карточек.
- 24/24 публичных сертификата доступны, MIME соответствует сигнатуре файла.
- 139/139 JPEG-трансформаций доступны без токена, успешно декодируются,
  1600×1200; размер 59 477-278 705 байт. Обложка первая, лимит до 10 фото.
- У т24, т25, т26, т28 и т30 по пять опубликованных фото вместо шести.
  Это предупреждение, не блокер Avito. Новые изображения не выдумывались.
- 24/24 оригинала сертификатов отвечают HTTP 403 без авторизации.
- В HTML всех 24 карточек не обнаружены известные полные serial/IMEI из
  приватного склада или неидентифицированные 15-значные последовательности.
  Из проверки исключены только точные опубликованные ИНН/ОГРНИП магазина:
  15-значный ОГРНИП футера сначала дал ложный сигнал. Известные приватные
  значения блокируются даже при совпадении с legal allowlist.

Проверка не заменяет физическую повторную диагностику, визуальную сверку
каждого ракурса/QR публичного сертификата или приёмку кабинетом Avito.

## Обновлённая Книга

Файл: `outputs/avito-catalog-2026-10-04/ISVOI_Avito_PREPARATION_2026-10-04.xlsx`.
Исходный XLSX владельца не изменён. Сохранены официальные заголовки,
справочник, dropdown-правила и структура телефонного листа.

- `Перед загрузкой`: ограничения и последовательность QA; открывается первым.
- `Телефоны-Мобильные телефоны`: 16 кандидатов без базовых блокеров каталога.
- `Все доступные описания`: сбалансированные тексты для всех 19 товаров
  в наличии, включая три заблокированных.
- `Сверка всех устройств`: 32 строки с явными исключениями и предупреждениями.

Сохранены существующие стабильные ID канала. Цена берётся с сайта, а заданный
вручную price_override имеет приоритет и не сбрасывается. Закупка, маржа,
полные serial/IMEI, приватные оригиналы и внутренние заметки не включены.
Старые AvitoId, контакты и IMEI исторической строки исходного XLSX очищены.

В колонках фото и комплекта используется разделитель `|`, подтверждённый
комментариями I2/Y2 исходного шаблона. Подтверждённый комплект записан как
`Коробка | Провод зарядки`; блок питания не добавлен. Это подтверждение формата
XLSX, не структуры многозначного Set в XML.

RAM, состояние экрана/корпуса, запечатанность и каталожные сочетания
выделены жёлтым для подтверждения. RAM и неподтверждённые состояния не
выдуманы; оставленные пустыми обязательные поля означают, что **книга пока
не готова для загрузки в Avito**. Цвета являются предложениями, не доказательством
допустимости сочетаний официального каталога. IMEI остаётся пустым намеренно.

Описания учитывают реальные причины грейда B, отдельную проверку гарнитуры т9,
дату батареи/циклов, комплект и гарантию магазина 90 дней. Samsung не получает
проверки Face ID/True Tone или неподтверждённое утверждение об оригинальности
компонентов. Утверждённые тексты т11/т29/т37 сохранены при совпадении фактов;
новым индивидуальным текстам требуется редакторское QA.

Фид выключен, allowlist 1-3 ID сохранён. Полная подготовка 19 товаров не
является разрешением массовой публикации или расширением пилота.

Экспорт выполняет READ ONLY транзакцию и очищает известные приватные идентификаторы
на сервере до возврата результата. XLSX-генератор проверяет hash версии шаблона,
совпадение snapshot/preflight, отсутствие формул/Excel errors и очистку
контактных/приватных полей. Никакой apply-функции или автопубликации нет.

22 установки ключей и read-only API. Финальная книга повторно открыта:

скрытый справочник сохранён; IMEI/RAM не заполнены, разделители фото/комплекта
и цены/тексты совпадают с подготовкой. Формул, Excel error cells и полных
15-значных значений в книге нет. text:audit и git diff --check прошли.
Полный web:verify в этой итерации не запускался; ранее зафиксированные
посторонние ошибки форматирования не исправлялись. Проверки не являются
подтверждением приёмки кабинетом Avito.
