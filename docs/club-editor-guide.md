# I СВОИ Club: памятка редактора

Club работает как пилотный подбор по заявке. Это не интернет-магазин, публичная
оферта, личный кабинет или обещание заранее определённого выкупа.

## Ежедневная работа

1. Откройте `Настройки Club` и оставьте режим `Пилот · не индексировать`.
2. Редактируйте тексты страницы в тематических группах настроек.
3. Управляйте Base/Care в `Тарифы Club`; различия должны быть измеримыми.
4. Редактируйте сценарии цикла и Passport в `Процесс Club`.
5. Редактируйте правила только в `Правила Club`, используя русские категории.
6. Обрабатывайте заявки через сохранённые представления `Club: ...`.

Поля из группы `Расширенные настройки` меняются только вместе с разработчиком.
Строки не удаляйте физически: выключайте публикацию или переводите в черновик.

## Предложения

Пока предложений нет, посетитель указывает модель или категорию в форме
подбора. После публикации предложения оно автоматически появляется перед
формой.

Для опубликованного предложения обязательны устройство, тариф, минимальный
срок, условия и один из режимов цены:

- утверждённая сумма `от ... ₽/мес`;
- явный ручной расчёт без публичного обещания цены.

Карточка ведёт на товар основного сайта, а CTA выбирает предложение в форме.

## Тарифы и правила

Base и Care должны отличаться минимум по двум параметрам: сопровождение, срок
ответа, диагностика, подменное устройство, досрочный выход или повреждения.
Незаполненные и юридически не проверенные обещания не публикуйте.

Для нормального износа приводите конкретные примеры. Отдельно поддерживайте
правила повреждений, возврата, выкупа, досрочного выхода, просрочки, потери,
данных/Apple ID и сервиса.

## Документы и индексация

Документы ведутся в `Документы Club` с типом, версией, датой действия и статусом
юридической проверки. Наличие записи в Directus не означает юридического
заключения.

До запуска должны быть опубликованы и вручную проверены:

- политика обработки данных;
- условия пилота;
- проект договора.

Переключение в `public_index` выполняет администратор только после зелёных:

```bash
npm run directus:audit-club
npm run directus:audit:prod
```

Кроме Directus действует серверный gate `CLUB_INDEXING_ENABLED`. Пока он равен
`0`, Club остаётся `noindex` независимо от ошибки редактора.

## Заявки

В заявке проверяйте:

- выбранное предложение либо `Запрошенное устройство`;
- тариф, срок и комфортный платёж;
- источник и UTM;
- версию и время согласия;
- ответственного, статус и следующий контакт.

Не переносите модель устройства только в общий комментарий: для неё есть
структурированное поле.
